# NovaCare Clinic

A professional clinic website built with HTML, CSS, and JavaScript.

## Features
- Responsive design — works on mobile and desktop
- Services section with 6 medical specialties
- Doctor profiles
- WhatsApp appointment booking form
- Patient testimonials
- Contact section with location and hours

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome icons
- Google Fonts
